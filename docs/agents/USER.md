- **Will not connect the bank** to the app. Might consider connecting the accounting tool; unsure.
- Wants approval before anything is linked (matches go to a queue, never silently).
- Wants to be asked before production changes; typically answers "push to main" when ready.
- Cost-conscious: no fast mode / pricier models without asking; test before switching models.

## How to work with Luca

- Reply in plain language, short, no jargon. Lead with the answer or the result.
- Say what was verified and what wasn't (e.g. "built, not yet live").
- When something is a decision for him, present the recommendation and ask once.
- He sends screenshots; if something "isn't there", first check whether it's deployed and where it lives.
